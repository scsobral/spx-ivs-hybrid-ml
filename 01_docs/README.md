# Documentation & Academic Publications

This directory contains the official academic deliverables for the master's dissertation:

* **Author:** Sérgio da Cunha Sobral
* **Degree:** Master in Financial Mathematics (*Mestrado em Matemática Financeira*)
* **Institution:** ISCTE – Instituto Universitário de Lisboa (ISCTE-IUL), Lisbon, Portugal
* **Departments:** Department of Finance & Department of Mathematics
* **Supervisor:** Prof.ª Doutora Diana Elisabeta Aldea Mendes (Associate Professor, ISCTE-IUL)
* **Date:** October 2025
* **Classification / Grade:** **19 / 20** (Distinction)

## Documents Included

| File | Format | Description |
| :--- | :---: | :--- |
| **[`thesis_master_sergio_sobral.pdf`](thesis_master_sergio_sobral.pdf)** | PDF (7.1 MB) | **Full Master's Dissertation.** Complete theoretical foundations (Black-Scholes-Merton framework, volatility smile/skew, non-arbitrage constraints), data engineering on 10 years of CBOE SPX options (2009–2019), classical models (OLS, 5th-degree Polynomial, Cubic B-Splines), Machine Learning (Random Forest, XGBoost), and Hybrid ML architectures with comprehensive out-of-sample empirical evaluation. |
| **[`thesis_presentation_sergio_sobral.pdf`](thesis_presentation_sergio_sobral.pdf)** | PDF (2.6 MB) | **Thesis Defense Slide Deck.** Official visual presentation used during the thesis defense before the academic jury, highlighting research questions, methodologies, comparative 3D surfaces, error metrics, and key empirical conclusions. |
